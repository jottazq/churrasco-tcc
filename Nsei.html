📚 Resumo — Linux, PHP e Banco de Dados

🐧 Terminal Linux

📁 Navegação

  • pwd → mostra onde você está.
  • ls → lista arquivos e pastas.
  • cd → entra em uma pasta.
  • cd .. → volta uma pasta.
  • clear → limpa o terminal.

📄 Arquivos e Pastas

  • mkdir → cria uma pasta.
  • touch → cria um arquivo.
  • cp → copia arquivos ou pastas.
  • mv → move ou renomeia.
  • rm → apaga arquivos.
  • rmdir → apaga pasta vazia.
  • cat → mostra o conteúdo de um arquivo.
  • nano → edita arquivos.
  • man → mostra o manual de um comando.

🔐 Permissões

  • r → leitura = 4
  • w → escrita = 2
  • x → execução = 1
  • chmod → altera permissões.
  • chown → altera o proprietário.
  • chgrp → altera o grupo.

📊 Valores das Permissões

  • 7 → rwx → lê, escreve e executa.
  • 6 → rw- → lê e escreve.
  • 5 → r-x → lê e executa.
  • 4 → r-- → apenas lê.
  • 0 → --- → nenhuma permissão.

👤 Usuários

  • whoami → mostra o usuário atual.
  • id → mostra informações do usuário e seus grupos.
  • sudo → executa um comando como administrador.

📦 Programas

  • sudo apt update → atualiza a lista de pacotes.
  • sudo apt upgrade → atualiza programas.
  • sudo apt install programa → instala um programa.
  • sudo apt remove programa → remove um programa.

🔎 Pesquisa

  • find → procura arquivos e pastas.
  • grep → procura palavras ou textos dentro de arquivos.

⚙️ Processos

  • ps → mostra processos.
  • top → mostra processos em tempo real.
  • kill → encerra um processo.

⭐ Comandos mais importantes

ls = listar | cd = entrar | mkdir = criar pasta | touch = criar arquivo | cp = copiar | mv = mover/renomear | rm = apagar | chmod = permissões | sudo = administrador

🐘 PHP e Banco de Dados

📦 Arrays

Array é usado para armazenar vários valores dentro de uma única variável.

🔢 Array Indexado

Usa números como índices, começando normalmente pelo 0. 

$frutas = ["Maçã", "Banana", "Uva"];

echo $frutas[0];

Resultado: Maçã

🏷️ Array Associativo

Usa nomes como chaves em vez de números. 

$pessoa = [
    "nome" => "João",
    "idade" => 18
];

echo $pessoa["nome"];

🗂️ Array Multidimensional

É um array que possui outros arrays dentro dele. 

$alunos = [
    ["João", 18],
    ["Maria", 17]
];

echo $alunos[0][0];

🗄️ Banco de Dados

O banco de dados serve para armazenar e organizar informações.

➕ Criando um Banco de Dados

CREATE DATABASE escola;

📋 Criando uma Tabela

CREATE TABLE alunos (
    id INT AUTO_INCREMENT PRIMARY KEY,
    nome VARCHAR(100),
    idade INT
);

🔌 Conectando ao Banco de Dados

O PHP pode utilizar o mysqli para se conectar ao MySQL. 

$conn = new mysqli(
    "localhost",
    "root",
    "",
    "escola"
);

➕ Inserindo Dados

INSERT INTO adiciona dados em uma tabela. 

INSERT INTO alunos (nome, idade)
VALUES ("João", 18);

🔎 Consultando Dados

SELECT serve para consultar dados. 

SELECT * FROM alunos;

📤 Consulta usando PHP

$sql = "SELECT * FROM alunos";

$resultado = $conn->query($sql);

while ($aluno = $resultado->fetch_assoc()) {
    echo $aluno["nome"];
}

📎 Função Include

A função include permite utilizar o conteúdo de outro arquivo PHP dentro do arquivo atual. 

include "conexao.php";

É muito utilizada para reaproveitar códigos, como conexões com banco de dados, menus e cabeçalhos.

⭐ Para Decorar

  • Array indexado → índices numéricos.
  • Array associativo → chaves com nomes.
  • Array multidimensional → array dentro de array.
  • CREATE DATABASE → cria banco de dados.
  • CREATE TABLE → cria tabela.
  • INSERT INTO → insere dados.
  • SELECT → consulta dados.
  • mysqli → conecta PHP ao MySQL.
  • include → inclui outro arquivo PHP.
