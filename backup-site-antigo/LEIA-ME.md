# Backup do site antigo

Cópia fiel do site **como estava antes do painel de administração**
(último commit antes da mudança: `4988ee0`, de 22/11/2026).

- Tudo aqui é HTML estático, igual ao que estava no ar antes.
- Esta pasta **não é servida pelo site**: o `.htaccess` dela bloqueia o acesso pelo navegador.
- Para consultar ou voltar atrás, abra os arquivos pelo GitHub ou baixe a pasta.
- Para restaurar o site antigo por inteiro, copie o conteúdo desta pasta para a raiz do site
  (e apague as páginas `.php` e as pastas `admin`, `includes`, `install` e `database`).
